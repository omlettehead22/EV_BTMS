# Panasonic NCR18650PF validation subset

Processed from P. Kollmeyer, *Panasonic 18650PF Li-ion Battery Data*, Mendeley Data v1 (2018), doi:10.17632/wykht8y7tg.1, licensed **CC BY 4.0**. The tests were performed at the University of Wisconsin-Madison by Dr. Phillip Kollmeyer.

Changes from the original: tests selected, non-finite and duplicate-time samples removed, resampled to exact 1 s bin means (current sign flipped so discharge is positive), battery case temperature interpolated at bin centres, ambient taken from the chamber channel only where it agrees with the setpoint. Generated by `validation/prepare_panasonic.py`.
